## Primary competency

My primary competency is responsive CSS and inclusive visual design, with keyboard accessibility as a major focus for this contract. For this contract, I am targeting only these parts of that competency:

- Mobile-first grid layout for the packaging gallery cards
- Typography, spacing, and clear visual hierarchy for easier reading and scanning
- Organized shared styles using custom properties and consistent component rules
- Keyboard accessibility with visible focus states and logical tab order
- A view more button on each card that reveals more information without crowding the page
- Responsive behavior so the gallery stays usable on narrow and wide screens

I am not claiming that this contract completes the full responsive CSS or accessibility competency. I am focusing on the parts that will improve both the layout and usability of my Packaging Design Gallery, while also carrying forward the feedback from my peer review about adding more interaction and data-driven features.
